# Задача 1. Розширення функціоналу префіксного дерева

Клас `Homework` наслідує `Trie` і додає два методи:

- `count_words_with_suffix(pattern) -> int` — кількість слів, що закінчуються на `pattern`;
- `has_prefix(prefix) -> bool` — чи існує хоча б одне слово з таким префіксом.

## Алгоритм

**`has_prefix`.** Проходимо по символах префікса від кореня прямого дерева. Якщо якогось
переходу немає — `False`; якщо префікс пройдено повністю — `True`. Складність — **O(m)**,
де m — довжина префікса.

**`count_words_with_suffix`.** Пошук суфікса у прямому дереві потребував би обходу всього
дерева (O(N·L)). Тому `Homework` перевизначає `put` і паралельно будує *дзеркальне* дерево
слів, записаних навпаки. У кожному вузлі зберігається лічильник слів, що проходять через
нього, тобто кількість слів із відповідним суфіксом. Для запиту достатньо пройти
`reversed(pattern)` і повернути лічильник вузла — **O(m)**. Повторне додавання того самого
слова лічильники не змінює.

## Обробка некоректних даних і крайніх випадків

- Не-рядок у `pattern`/`prefix` → `TypeError`.
- Відсутність збігів → `0` / `False`; регістр враховується.
- Порожній рядок поводиться як у `str.endswith("")` / `str.startswith("")`: збігається з
  кожним словом (для порожнього дерева — `0` / `False`).

## Складність

| Операція | Час | Пам'ять |
|---|---|---|
| `put` | O(L) | +O(L) на дзеркальне дерево |
| `count_words_with_suffix` | O(m) | O(1) |
| `has_prefix` | O(m) | O(1) |

## Емпіричні результати (`python benchmark.py`, 199 484 унікальних випадкових слів)

| Метод | Trie | Послідовний перебір `endswith` |
|---|---|---|
| 5 запитів `count_words_with_suffix` | 1.3 мкс | 54.3 мс |
| 5 запитів `has_prefix` | 1.1 мкс | — |

Побудова дерева займає ~4 с (одноразово); запити швидші приблизно у 42 000 разів.
Результати `count_words_with_suffix` звірено з наївною реалізацією.

## Запуск


## Висновки

Дзеркальне дерево з лічильниками переносить вартість підрахунку суфіксів на етап
побудови, за що запити виконуються за час, що залежить лише від довжини шаблону.
